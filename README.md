# Matkontroll

**Vit hva du spiser.**

Mobilapp under utvikling. Vi starter med en Expo/React Native-prototype med eksempelprodukter og bygger senere integrasjon med Open Food Facts og Django.

## Produktvisjon

Skann en matvare, forstå ingredienser, bearbeidingsgrad og næringsinnhold, og sammenlign alternativer. Ingen kaloritelling eller pekefinger.

## Neste steg

Sett opp Expo-appen i `mobile/` og bygg søk, produktvisning og sammenligning. Produktdata i prototypen skal merkes som fiktive.

Arbeidsnavnet Matkontroll er ikke varemerkeavklart.
